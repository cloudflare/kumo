{/* Architecture */}

<ComponentSection>
  <Heading level={2}>Architecture</Heading>
  <p>
    The CreateResource block follows a data-driven, controlled component
    pattern:
  </p>
  <ul class="list-disc space-y-2 pl-6">
    <li>
      <strong>Controlled state:</strong> You own the step index and manage
      navigation through `step` and `onStepChange` props.
    </li>
    <li>
      <strong>Step definitions:</strong> Pass an array of step objects with
      `key`, `label`, and `content`. Each step's content is typically a
      `CreateResourceStep`.
    </li>
    <li>
      <strong>Consumer-owned navigation:</strong> The block handles layout and
      animation. You handle validation, async operations, and button rendering
      in each step's `footer`.
    </li>
    <li>
      <strong>Exit handling:</strong> Use the `onClose` callback to handle
      routing when the user clicks the X button.
    </li>
  </ul>
</ComponentSection>

{/* Accessibility */}

<ComponentSection>
  <Heading level={2}>Accessibility</Heading>
  <ul class="list-disc space-y-2 pl-6">
    <li>
      <strong>Focus management:</strong> Focus automatically moves to each step
      after animation completes.
    </li>
    <li>
      <strong>Focus trap:</strong> Tab navigation is constrained to the current
      step's content, the previous step card (for back navigation), and the
      close button.
    </li>
    <li>
      <strong>Keyboard navigation:</strong> Previous step cards can be activated
      with Enter or Space.
    </li>
    <li>
      <strong>Reduced motion:</strong> Respects `prefers-reduced-motion` -
      animations are disabled when the user prefers reduced motion.
    </li>
  </ul>
</ComponentSection>
