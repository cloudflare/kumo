## Resizable Columns

Enable column resizing by setting `enableColumnResizing: true` in the table options. Users can drag column borders to adjust widths. Refer to the [TanStack column sizing guide](https://tanstack.com/table/v8/docs/guide/column-sizing) for advanced configuration options.

<ComponentExample demo="TanstackResizableDemo">
  <TanstackResizableDemo client:visible />
</ComponentExample>

For a smoother resizing experience, add a filler column that absorbs excess space. Configure `minSize` and `size` on columns to control their resizing behavior.
