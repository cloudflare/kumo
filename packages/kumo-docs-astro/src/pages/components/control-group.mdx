## Usage

Use `ControlGroup` when multiple standalone controls should read as one compact
toolbar or filter card. Supported child controls automatically inherit the group
size and adjust borders, radii, labels, and descriptions for the grouped layout.

```tsx
import { Button, ControlGroup, Input } from "@cloudflare/kumo";

export default function Example() {
  return (
    <ControlGroup size="sm">
      <Input type="text" placeholder="Search..." aria-label="Search" />
      <Button>Edit</Button>
      <Button>Add</Button>
    </ControlGroup>
  );
}
```

</ComponentSection>

## Behavior

`ControlGroup` intentionally owns grouped control presentation:

- Child `size` props are ignored and replaced by the group `size`.
- `Button` and `LinkButton` children render as ghost buttons.
- Labels on controls like `Input`, `Select`, and `Combobox` stay accessible but are visually hidden.
- Descriptions on grouped controls are ignored to keep the row compact.
- Adjacent controls share borders and only the outer corners are rounded.
