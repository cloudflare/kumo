## Usage

`RefreshButton` is a thin wrapper around `Button` that pins `shape="square"`,
ships the rotating arrows icon, and supplies a sensible default `aria-label`
of `"Refresh"`. It also animates the icon while `loading` is `true`.

```tsx
import { RefreshButton } from "@cloudflare/kumo";

export default function Example() {
  return <RefreshButton onClick={refetch} loading={isFetching} />;
}
```

The `loading` prop only spins the refresh icon — it intentionally does not
swap in the standard Button loader, which would replace the refresh affordance.
