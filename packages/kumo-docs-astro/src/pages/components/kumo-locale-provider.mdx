<p>
  Kumo components come with default English text. To localize them, wrap your
  app with <code>KumoLocaleProvider</code> and provide a{" "}
  <code>translations</code> object. Only specify the keys you want to override —
  the rest will fall back to English defaults. The <code>KumoTranslations</code>{" "}
  type is exported from <code>@cloudflare/kumo</code> for TypeScript
  autocompletion.
</p>
