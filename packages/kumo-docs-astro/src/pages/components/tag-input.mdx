## Usage

Use `value` with `onValueChange` to control the tags. Use `defaultValue` for uncontrolled usage.

```tsx
const [tags, setTags] = useState<string[]>([]);

<TagInput
  label="Labels"
  value={tags}
  onValueChange={setTags}
  placeholder="Add a label"
/>
```

### Forms
Set `name` to submit each tag as a separate form value, so `FormData.getAll(name)` returns the tags. Text still in the input becomes a tag when focus leaves it, so clicking a submit button includes it. `required` passes once there's at least one tag.
<ComponentExample demo="TagInputFormDemo"><TagInputFormDemo client:load /></ComponentExample>

### Read-only
`readOnly` shows the tags and keeps the input focusable, but tags can't be added or removed. Like a native read-only input, it's skipped by form validation, even when `required` is set.

## Behavior

Press Enter, comma, or Tab to create a tag. Blur also commits the current value. Pasting comma- or newline-separated text inserts it into the current text at the cursor, then creates each value synchronously. Pasting text without a separator works like a normal paste. Duplicate values are ignored.

## Localization

Use `labels` to translate all TagInput-generated text: the fallback input name, tag removal action, invalid-value feedback, and maximum-value feedback.

```tsx
<TagInput
  label="Etiquetas"
  labels={{
    input: "Agregar etiqueta",
    removeValue: (value) => `Eliminar ${value}`,
    invalidValue: (value) => `${value} no es valido.`,
    maxValuesReached: (maxValues) => `Maximo de ${maxValues} etiquetas.`,
  }}
/>
```
