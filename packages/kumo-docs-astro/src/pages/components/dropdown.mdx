## Usage

```tsx
import { DropdownMenu, Button } from "@cloudflare/kumo";

export default function Example() {
  return (
    <DropdownMenu>
      <DropdownMenu.Trigger render={<Button>Menu</Button>} />
      <DropdownMenu.Content>
        <DropdownMenu.Item onClick={() => console.log("edit")}>
          Edit
        </DropdownMenu.Item>
        <DropdownMenu.Item onClick={() => console.log("duplicate")}>
          Duplicate
        </DropdownMenu.Item>
        <DropdownMenu.Separator />
        <DropdownMenu.Item
          variant="danger"
          onClick={() => console.log("delete")}
        >
          Delete
        </DropdownMenu.Item>
      </DropdownMenu.Content>
    </DropdownMenu>
  );
}
```

### Inset Items

<p>
  When any item in a menu has an icon, items without one (including labels)
  are inset automatically so their text lines up. Use `inset` to force the
  inset when automatic detection can't see the icon, for example when an item
  renders its own content through `render`.
</p>

## API Reference

### DropdownMenu

<p>Root component that manages the dropdown state.</p>
<PropsTable component="DropdownMenu" />

### DropdownMenu.Trigger

<p>Button that opens the dropdown when clicked.</p>
<PropsTable component="DropdownMenu.Trigger" />

### DropdownMenu.Content

<p>
  The menu popup. Combines `Portal`, `Positioner` and `Popup`: positioning
  props such as `side`, `align`, `sideOffset` and `alignOffset` go to the
  Positioner, and `className` goes to the Popup.
</p>
<PropsTable component="DropdownMenu.Content" />

### DropdownMenu.Portal, Positioner and Popup

<p>
  The parts `Content` is built from. Compose them directly when you need to
  style or configure the Positioner and Popup separately. `Portal` respects
  `KumoPortalProvider`, and `Popup` carries the menu surface styles and
  open/close animation.
</p>

```tsx
<DropdownMenu.Portal>
  <DropdownMenu.Positioner side="top" align="end">
    <DropdownMenu.Popup className="min-w-56">
      <DropdownMenu.Item>Edit</DropdownMenu.Item>
    </DropdownMenu.Popup>
  </DropdownMenu.Positioner>
</DropdownMenu.Portal>
```

<p>
  Both accept the same props as Base UI's `Menu.Positioner` and `Menu.Popup`.
  See the [Base UI Menu docs](https://base-ui.com/react/components/menu) for
  the full list.
</p>

### DropdownMenu.Item

<p>Individual menu item for actions.</p>
<PropsTable component="DropdownMenu.Item" />

### DropdownMenu.LinkItem

<p>
  A menu item that navigates to a URL. Renders a semantic `<a>` element. Use this instead of `Item` for navigation links.
</p>
<PropsTable component="DropdownMenu.LinkItem" />

### DropdownMenu.CheckboxItem

<p>
  A menu item that can be toggled on or off. Use for independent boolean
  options.
</p>
<PropsTable component="DropdownMenu.CheckboxItem" />

### DropdownMenu.Sub

<p>
  Root component for a nested submenu. Wrap SubTrigger and SubContent inside
  this.
</p>
<PropsTable component="DropdownMenu.Sub" />

### DropdownMenu.SubTrigger

<p>
  Menu item that opens a nested submenu when hovered or clicked. Displays a
  caret icon automatically and stays highlighted while its submenu is open.
  Like `Item`, its `icon` prop accepts a Phosphor icon component or a rendered
  element.
</p>
<PropsTable component="DropdownMenu.SubTrigger" />

### DropdownMenu.SubContent

<p>
  Container for submenu items. Positioned relative to the SubTrigger. When the
  submenu sits beside its trigger, it cancels the popup padding so the first
  item lines up with the trigger and overlaps the parent menu slightly. If
  there isn't room and it moves above or below the trigger, it uses the same
  spacing as a top-level menu. Pass `sideOffset` or `alignOffset` (a number or
  a function of the resolved `side`) to override.
</p>
<PropsTable component="DropdownMenu.SubContent" />

### DropdownMenu.Separator

<p>A visual divider between menu items.</p>
<PropsTable component="DropdownMenu.Separator" />

### DropdownMenu.RadioGroup

<p>
  Groups radio items for single-selection behavior. Only one item can be
  selected at a time.
</p>
<PropsTable component="DropdownMenu.RadioGroup" />

### DropdownMenu.RadioItem

<p>
  A menu item that works like a radio button. Must be used inside a RadioGroup.
</p>
<PropsTable component="DropdownMenu.RadioItem" />

### DropdownMenu.RadioItemIndicator

<p>
  Shows the selected state for a RadioItem. Displays a checkmark by default.
</p>
<PropsTable component="DropdownMenu.RadioItemIndicator" />
