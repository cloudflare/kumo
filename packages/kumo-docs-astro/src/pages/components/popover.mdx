## Usage

```tsx
import { Popover, Button } from "@cloudflare/kumo";

export default function Example() {
  return (
    <Popover.Root>
      <Popover.Trigger render={<Button />}>Open</Popover.Trigger>
      <Popover.Portal>
        <Popover.Positioner>
          <Popover.Popup>
            <Popover.Arrow />
            <Popover.Title>Popover Title</Popover.Title>
            <Popover.Description>Popover content goes here.</Popover.Description>
          </Popover.Popup>
        </Popover.Positioner>
      </Popover.Portal>
    </Popover.Root>
  );
}
```

## Popover vs Tooltip

  <p>
    While popovers can be triggered on hover (using `openOnHover`), they serve a
    different purpose than tooltips. Understanding when to use each is important
    for accessibility and user experience.
  </p>
  <div class="overflow-hidden rounded-lg border border-kumo-hairline">
    <table class="w-full text-sm">
      <thead class="bg-kumo-elevated">
        <tr>
          <th class="px-4 py-3 text-left font-semibold"></th>
          <th class="px-4 py-3 text-left font-semibold">Tooltip</th>
          <th class="px-4 py-3 text-left font-semibold">Popover</th>
        </tr>
      </thead>
      <tbody class="divide-y divide-kumo-hairline">
        <tr>
          <td class="px-4 py-3 font-medium">Purpose</td>
          <td class="px-4 py-3 text-kumo-subtle">
            Short, non-interactive text labels for identification
          </td>
          <td class="px-4 py-3 text-kumo-subtle">
            Rich, interactive content containers
          </td>
        </tr>
        <tr>
          <td class="px-4 py-3 font-medium">Content</td>
          <td class="px-4 py-3 text-kumo-subtle">Plain text only</td>
          <td class="px-4 py-3 text-kumo-subtle">
            Any content: links, buttons, forms, images
          </td>
        </tr>
        <tr>
          <td class="px-4 py-3 font-medium">Trigger</td>
          <td class="px-4 py-3 text-kumo-subtle">Hover or focus</td>
          <td class="px-4 py-3 text-kumo-subtle">Click (default) or hover</td>
        </tr>
        <tr>
          <td class="px-4 py-3 font-medium">ARIA Role</td>
          <td class="px-4 py-3">
            `role="tooltip"`
          </td>
          <td class="px-4 py-3">
            `aria-haspopup`
          </td>
        </tr>
        <tr>
          <td class="px-4 py-3 font-medium">Keyboard</td>
          <td class="px-4 py-3 text-kumo-subtle">Not focusable</td>
          <td class="px-4 py-3 text-kumo-subtle">
            Focus moves inside, traps when open
          </td>
        </tr>
      </tbody>
    </table>
  </div>
  <p>
    <strong>Use a Tooltip</strong> when you need to label an icon button or
    provide a brief explanation. <strong>Use a Popover</strong> when users need
    to interact with the content inside, such as clicking links, filling out
    forms, or dismissing with a button.
  </p>

### Deprecated Content compatibility

<p>
  `Popover.Content` is deprecated, but remains available so existing popovers do
  not break. It combines `Portal`, `Positioner`, `Popup`, and `Arrow` into one
  component and fades in smoothly using opacity only, without a scale or
  transform animation. New popovers should compose the individual parts as
  shown in the basic example.
</p>
<ComponentExample demo="PopoverLegacyContentDemo">
  <PopoverLegacyContentDemo client:load />
</ComponentExample>

### Scrollable content

<p>
  When the arrow and heading should remain fixed, place the overflowing content
  in an inner scroll container. Existing overflow styles on the deprecated
  `Popover.Content` remain supported by its fade-only transition.
</p>

  <PopoverOverflowDemo client:load />

### CSS variables

  popup animation.
</p>

<p>
  Use `openOnHover` on the trigger to open the popover when the user hovers over

### Virtual Anchor

<p>
  Use the `anchor` prop on `Popover.Positioner` to position the popover against
  an element other than the trigger, or against a virtual point (e.g., a
  `DOMRect` from `getBoundingClientRect()`). This is useful when the trigger and
  the desired anchor are in different component trees.

## API Reference

### Popover.Root

<p>The root component that manages the popover's open state.</p>
<PropsTable component="Popover" />

### Popover.Trigger

<p>
  A button that opens the popover when clicked. Use `render` to render your own
  element.
</p>
<PropsTable component="Popover.Trigger" />

### Popover.Portal

<p>
  Renders the popover outside the application DOM hierarchy. It uses the
  container from `KumoPortalProvider` by default and accepts a `container` prop
  to override it.
</p>
<PropsTable component="Popover.Portal" />

### Popover.Backdrop

<p>An optional backdrop rendered behind the popover.</p>
<PropsTable component="Popover.Backdrop" />

### Popover.Positioner

<p>
  Positions the popup relative to its trigger or an `anchor`. Use `side`,
  `align`, and their offset props to control placement.
</p>
<PropsTable component="Popover.Positioner" />

### Popover.Popup

<p>
  The styled popup container. Place `Popover.Arrow` and the popover content
  directly inside it.
</p>
<PropsTable component="Popover.Popup" />

### Popover.Arrow

<p>An optional arrow that points toward the popover's anchor.</p>
<PropsTable component="Popover.Arrow" />

### Popover.Viewport

<p>
  A viewport for animating content changes when one popup is shared by multiple
  triggers. It is not required for ordinary popovers or scrolling content.
</p>
<PropsTable component="Popover.Viewport" />

### Popover.Content

<p>
  A deprecated compatibility wrapper that combines `Portal`, `Positioner`,
  `Popup`, and `Arrow`. Existing usages remain supported, but new code should
  compose the individual parts shown above.
</p>
<PropsTable component="Popover.Content" />

### Popover.Title

<p>A heading that labels the popover for accessibility.</p>
<PropsTable component="Popover.Title" />

### Popover.Description

<p>A paragraph providing additional context about the popover content.</p>
<PropsTable component="Popover.Description" />

### Popover.Close

<p>
  A button that closes the popover when clicked. Use `render` to render your own
  element.
</p>
<PropsTable component="Popover.Close" />
